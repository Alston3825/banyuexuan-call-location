## 已开始的程序验证

`prototype/core.py` 是 Python 标准库实现的可替换业务参考内核，使用 SQLite 验证持久化、设备事件去重、多人接单互斥、服务状态转换、明确转交和事务内事件队列。它不决定最终技术栈，不包含 HTTP 服务或生产认证，不可接真实客户投入使用。

在项目目录运行：

```sh
python3 -m unittest discover -s tests -v
python3 -m prototype.demo
```

演示使用临时数据库和虚构房间/人员，不修改原始资料。最终后端技术栈在查看现有管理系统后决定；参考内核的规则和测试可迁移。
