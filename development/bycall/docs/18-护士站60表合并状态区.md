# 护士站60表合并状态区

日期：2026-11-20（America/Los_Angeles）。与本轮数字孪生定位基础改造配套，当前为本地开发版本，未再次部署N100。

## 布局

合并原“护理师”和“手表在线状态”为“手表与护理师”区域；主区域左右约34%/66%，右侧向左扩大。1920×1080默认6列×10行，至少60个位置；保留左侧进行中呼叫、最近已结束及平板状态。较低分辨率为5列并滚动，不为塞下60张卡片把文字无限缩小。超过60台时不隐藏设备；后台可配置60–120个位置。旧版保存40/48时页面按至少60显示，无须改现场配置数据。

每张真实设备卡片：

- 手表编号、当前佩戴人姓名；未佩戴与备用池状态明确区分。
- 在线/离线持续计时、电量；离线起点持久化，重复离线通知不重置，恢复心跳后清除。历史记录无离线起点时回退显示距最后心跳时长。
- 心率、血压、位置。卡片双击仍可打开该护理师呼叫记录；按SN稳定排序、刷新保留滚动位置与卡片节点，不因轮询跳回顶部。
- 位置显示对应表里的area名称，例如现场确认后登记的SPA馆南侧、托管室北侧、2401房间；字段为配置文本，不在程序内编造真实位置。无有效观测、过期、扫描异常分别提示；不沿用旧房间。

待登记位置仅是空槽，不生成虚构设备或体征。截图中的60块演示表、姓名、体征和区域只用于本机隔离布局验证，页面顶部明确标记，未写入现场。

## 心率与血压

用户确认默认**每分钟采样一次**。后台增加heart_rate_interval_s（30–300秒），主机WATCH_BIND基础策略与单表远程覆盖均支持。传感器采集在独立工作线程进行，同一服务不并发采集，不阻塞MQTT心跳；无传感器/权限或没有收到有效事件则不造值。传感器旧缓存事件不当成新采样，换人/服务重启后未完成的测量不归给新佩戴者。

心率有效期为max(90, 采样间隔×2)秒，上限600秒，默认120秒；位置有效期独立计算。心率不是逐秒连续监护，设备与厂家仍需实测。悬停数值可看测量时刻与单位（心率次/分，血压mmHg）。

用户确认手表血压能力尚不明确：卡片先显示“未提供”。本轮仅增加真实血压上报的兼容字段systolic/diastolic与存储、显示校验，**未实现或声称存在厂商血压采集**。没有厂家型号/SDK/测量接口，不从心率推算血压、不填模拟值。后续接入时必须同时上报收缩压与舒张压，校验成对及先后大小；测量时间有时区，接收时间由主机记录。

```json
{"type":"VITALS_REPORT", "payload":{"staff":"示例员工", "heart_rate":78,
 "systolic":120, "diastolic":80, "measured_at":"2026-11-20T10:00:00+00:00"}}
```

示例仅说明字段，不代表当前手表会发送血压。不允许单独一项压力值；血压默认10分钟有效，过期/设备离线不作为实时值显示。心率新样本不会覆盖并抹掉已有有效血压，反之亦然；同员工换到另一块表、同表换人后不会继承之前的体征。数字孪生只读位置接口不包含这些体征。

## 发布与验收

本轮大屏数据结构与定位过期判断需要更新host；原浏览器页面随主机更新后自动重载。每分钟心率、扫描过滤与诊断需要安装新版手表；平板原呼叫协议兼容，无须为本轮强制重装。正式发布前仍需确认现场版本、备份、签名与实际业务状态。

本机软件回归、编译、页面验证结果见根目录当前开发任务。现场需验证60表可读性、离线恢复、每分钟真实心率及耗电、信标区域命名、熄屏/漫游；血压待取得厂商能力再接。当前实物在线情况仍以前一版本现场核验为准，本轮没有重新发布。
