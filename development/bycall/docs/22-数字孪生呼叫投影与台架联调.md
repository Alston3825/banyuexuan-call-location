# 数字孪生呼叫投影与双屏台架联调

日期：2026-11-21（America/Los_Angeles）。云端分支 `claude/project-thread-tsvsnd`，未合入 main、未发布 N150。流程总文档见 claude.ai 项目文档“伴月轩呼叫定位系统 × 数字孪生 对接联调开发流程”。

## 用户决定（2026-11-21）

3D 屏由 N150 双输出；数字孪生网关放在 N150 上作为独立容器；3D 人物显示员工姓名和岗位；3D 显示呼叫类型；护理师、送餐、保洁、前台都佩戴手表进入定位；首轮信标点位为护理站、2414、2415、走廊。房间键是否统一为 2407–2429 门牌号、是否先回流 ui-redesign 与 Android 7 兼容、网关端口仍待确认（台架暂用 8300）。

## 本轮代码

| 文件 | 内容 |
| --- | --- |
| host/bycall/core/twin_calls.py | `bycall.call.v1` 全量呼叫投影：进行中 + 60 秒内结束；source_epoch/sequence/revision；无语音、转写、自由文字 |
| host/bycall/api/app.py | `GET /integration/twin/calls`，复用 `BYCALL_TWIN_KEY` 只读鉴权（未配置 503，错误 401），no-store |
| host/bycall/core/screen_state.py、service.py | 定位投影每人增加 `display_name`、`role`、`role_name`（仍无体征、电量、last_known） |
| integration/twin-call-state.mjs | 3D 呼叫适配器：拒绝乱序/旧会话/同序号冲突，8 秒断流清空光圈，房间不在模型中标 unplaced 不猜位置 |
| host/tools/twin_bench.py、twin_bench_store.json | 台架联调脚本（扮演手表/平板，经 MQTT→主机→网关核对 T1–T9）与虚构 24F 台架配置 |

呼叫项字段：call_id、version、room、floor、kind、service_code、label、priority、state（pending/claimed/arrived/completed/cancelled）、owner_staff、owner_name、requester_staff（仅员工求助）、created_at、claimed_at、arrived_at、ended_at、transfer_pending、transferred。“到场/完成”只以主机事件为准，3D 不得凭人物区域推断。主机的超时升级派单不产生事件，投影里没有“已升级”字段；转交用 transferred/transfer_pending 表示。

## 台架联调结果

环境：云端容器，本机 mosquitto + 主机进程（`python -m bycall.main`，台架配置）+ 数字孪生网关（另一仓库 twin-gateway/server.py）+ 无头 Chromium（SwiftShader 软件渲染）。全部为虚构数据。

| 用例 | 结果 |
| --- | --- |
| T1 新呼叫两屏可见 | 通过，网关可见 1.3–2.0 秒（目标 ≤4 秒） |
| T2 接单→到场→完成 | 通过，3D 与文字屏顺序一致 |
| T3 转交/取消/紧急 | 通过 |
| T4 区域定位两屏同一事实 | 通过，同一 sequence 下 revision 与区域字段一致；姓名/岗位正确（含送餐、前台） |
| T5 跨区域切换 | 通过 |
| T6 位置过期 | 通过，两屏均 stale 且 zone_id 为空 |
| T7 换表 | 通过，同一人物，旧表位置不带过来；备用表上报后恢复 |
| T8 主机重启 | 通过，网关立即报 down；3D 页 8 秒内显示“数据连接中断”并隐藏人物与光圈，恢复后 8 秒内重建，新会话不回放旧位置 |
| T9 映射缺失 | 通过，主机仍判 fresh，网关 health 报 missing_zones，3D 不放置该人物 |
| T10 N150 双屏压力 | 未做，需要实机 |

复现：`python tools/twin_bench.py --admin-key <台架密钥> --restart-cmd <重启脚本> --json-out out.json`。不要对现场主机运行。

## 已知限制

- 软件渲染下一帧 3D 需要数秒，会让页面超过 8 秒没处理新数据而显示“连接中断”。这是正确的保护行为，但说明 N150 上必须实测帧率（T10）；页面新增 `?fps=N` 可限制绘制帧率。
