# Android 7平板安装兼容

2026-11-21：用户新7寸平板为Android 7.1.1（API25），旧平板APK最低API26（Android8.0），存在明确安装版本门槛；“解析错误”也可能由文件损坏或厂商安装器造成，不能仅凭提示排除其他原因。

将tablet和common的minSdk从26改24（Android7.0），手表保持26。保留包名与原调试签名，版本号按构建时间增加，可覆盖原同签名测试包。平板debug明确启用v1与v2签名，兼容旧/定制安装器。没有降低targetSdk或替换MQTT协议。API24提供当前共享模块所用CompletableFuture等接口，tablet/common lint检查无NewApi错误。未使用tools:overrideLibrary绕过最低版本检查。

最终包放根目录dist/tablet-android7-20261121，SHA256、版本与签名验证记录随包保存。该目录属于本地交付物，不纳入GitHub源码备份；构建源码与本文进入私有备份。

验证：平板assembleDebug、lintDebug通过（0 errors，8 warnings）；共享配置9项单元测试强制重新运行通过；共享最低版本修改后的手表assembleDebug通过。最终APK最低API24、API25签名校验及与既有平板证书一致性检查通过。没有API25模拟器/真实平板运行证据，不声称实机安装或运行已验收。未连接或升级N100、未发送终端升级通知。

安装：完整复制新APK到平板本地存储，允许未知来源并点击安装；首次使用允许录音权限，进入设置填写该平板独立设备编号、房间和已有主机/MQTT连接参数，勿复制另一房间设备身份。Android7的未知来源一般是系统安全设置中的全局开关，与Android8逐应用授权不同。

试测：启动与横屏显示→连接主机→点击客户呼叫并核对护士站/手表收到→录音发送和接收播放→断网重连→退出/重启后配置保留与开机拉起。7寸具体分辨率与厂商后台限制需实机核验。若仍解析失败，先比对包大小/哈希及确认下载完成；若可用ADB，记录adb install -r返回的具体错误，再定位签名、存储、系统定制等原因。不要先卸载清除既有设置。
