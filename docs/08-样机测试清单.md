# 样机到手后的测试清单

适用:手表、房间平板、蓝牙信标样机到手,在**真实设备 + 真实 Wi-Fi + 一台真实主机**上验证模拟器测不了的项目。软件在模拟器和本机 Mosquitto 上的联调已通过(见 05 号文档“当前状态汇总”),本清单只列**还没验证**的。

**级别**:**P0** = 试点上线前必须通过,不过就不下批量单;**P1** = 应通过,不过要有解决办法;**P2** = 观察记录,用于调参。
**标准来源**:标“(已定)”的来自《智能手表功能要求 V0.4》第五节验收;标“(已确认)”的是你 2026-11-10 逐项确认过的数值;仍标“(建议)”的是我给的试行值,**还没确认**。

**需要准备**

| 监控 | 另开终端运行 `python tools/watch_monitor.py <主机IP> --user host --password <host密码> --csv 记录.csv`:实时显示每块手表的位置上报/心跳/心率,间隔超过 3 倍节奏会标 `<<<`,可直接导出 CSV 画电量曲线 |
